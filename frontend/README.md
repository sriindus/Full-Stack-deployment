# frontend

React + TypeScript + Redux Toolkit client for the `java-fsd-hello-world` project. See the
[repo-level README](../README.md) for the full quickstart (this app, the Spring Boot backend,
Docker Compose, and Kubernetes).

```bash
cp .env.example .env.local
npm install
npm run dev     # http://localhost:5173
npm test
npm run build
```
